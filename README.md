# Крестик — PWA для вышивки крестом

Фотография → схема с нитками DMC → отметка прогресса пальцем прямо на схеме.
Всё считается в браузере: фото никуда не отправляется, интернет нужен только
на первое открытие.

## Файлы

```
index.html              всё приложение: вёрстка, стили, квантование, холст
sw.js                   service worker, кэш приложения (версия в VERSION)
manifest.webmanifest    имя, иконки, standalone-режим
fonts.css + fonts/      Inter, JetBrains Mono, Unbounded (latin + cyrillic)
icons/                  192/512 + maskable
nginx.conf              кэш-заголовки: sw.js — no-store, шрифты — immutable
Dockerfile              nginx:alpine со статикой внутри
docker-compose.yml      разворот за Traefik
```

## Запуск локально

```bash
python -m http.server 8765     # из этой папки
# открыть http://localhost:8765
```

Service worker работает на `localhost` и на HTTPS. По `http://` с IP-адреса
(например `http://192.168.1.10:8765`) браузер его не зарегистрирует — офлайна
не будет, но само приложение откроется.

## Разворот на VPS

```bash
docker network create traefik   # если сети ещё нет
# в docker-compose.yml поменяйте stitch.example.com на свой домен
docker compose up -d --build
```

Проверьте, что имя certresolver в лейблах (`letsencrypt`) совпадает с тем, что
настроен в вашем Traefik.

## Установка на телефон

- **Android/Chrome**: на главном экране появится плашка «Поставьте на телефон» → «Установить».
- **iOS/Safari**: «Поделиться» → «На экран „Домой“». Плашка с подсказкой покажется сама.

После установки приложение открывается без сети, схемы лежат в хранилище браузера.
`navigator.storage.persist()` запрашивается при старте, чтобы система не вычистила
данные при нехватке места — но это просьба, а не гарантия.

**Схемы живут только на этом устройстве.** Синхронизации между телефоном и компом
пока нет: переносите кнопкой «Файл схемы» (экспорт `.stitch.json`).

## Обновление версии

1. Правите `index.html`.
2. Меняете `VERSION` в `sw.js` (`stitchbook-v1` → `-v2`) — иначе старый кэш останется.
3. Пересобираете образ. У открытых клиентов появится плашка «Вышла новая версия».

## Что внутри

- Уменьшение картинки через canvas с усреднением по площади.
- k-means в CIE Lab (перцептивно корректно, не в RGB), затем привязка к 450 ниткам DMC.
- Лишние цвета сливаются по цене `крестики × расстояние до ближайшего цвета`, поэтому
  редкий, но контрастный цвет (жёлтые глаза кота) не исчезает первым.
- Символы раздаются от тёмного к светлому.
- Прогресс хранится битовой маской, в localStorage пишется в RLE.

RGB-значения DMC — общепринятая приблизительная конверсия. Финальный подбор
оттенков сверяйте с бумажной картой цветов.

## Чего ещё нет

- Печатный PDF из браузера (пока это делает `img2stitch.py`).
- Синхронизация между устройствами.
- Полукрест, бэкститч, другие палитры (Гамма, Anchor), цветная канва.
